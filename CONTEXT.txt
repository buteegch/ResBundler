ResBundler (Fabric 1.21.10) – Project Context

What this mod does
- Treats each folder inside the resourcepacks directory (that lacks pack.mcmeta) as a “combined” bundle containing multiple inner packs (directories with pack.mcmeta or .zip files).
- Orders inner packs by user-assigned numeric priority; unassigned entries (0) are sorted alphabetically at the bottom.
- Presents an in-game “Priorities” UI to edit these numbers per combined bundle.
- Bundles Cloth Config API so users don’t need to install it separately.

Runtime behavior
- Combined bundle detection: Top-level resourcepacks subfolder is considered a combined bundle if it does not contain pack.mcmeta.
- Inner pack filtering: Includes directories that have pack.mcmeta and .zip archives; ignores hidden names (starting with a dot).
- Sorting rules: Lower number = higher priority. Unassigned (0) sorts last among alphabetically sorted names.
- Resource resolution: Higher-priority packs override lower-priority entries when multiple inner packs provide the same resource.
- Config persistence: A simple text config the mod reads and writes under the Fabric config directory.

Config data file
- Path: Fabric config directory (FabricLoader.getConfigDir()).
- File name: combinedpacks_priority.txt.
- Format: Sections by combined folder name; lines mapping inner pack name to integer priority; missing or 0 treated as unassigned.

UI flow
- Open Resource Packs screen.
- Click “Priorities” button (top-right) to open the config screen.
- Each combined folder lists its inner packs with integer fields.
- Click Done to save priorities to combinedpacks_priority.txt.

Operational notes
- A folder with pack.mcmeta is treated as a normal pack; combined bundle logic applies only to folders without pack.mcmeta.
- Inner packs must be valid and readable; invalid paths are skipped silently.
- After changing priorities, resources can be reloaded by leaving/re-entering screen or via a reload control (future addition inside priorities UI).

Future extensions for handoff
- Add a “Reload Resources” button inside the priorities menu: either via Cloth Config’s button entry or a light client-side mixin targeting the Cloth Config screen instance to call client.reloadResources().
- Consider per-bundle enable/disable toggles and validation of integer ranges.
